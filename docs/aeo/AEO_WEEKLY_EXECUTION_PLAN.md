# QuickKitAI AEO Weekly Execution Plan
**Operating timezone:** Asia/Kolkata  
**Inventory:** 60 prompts / month; 4 weekly cycles × 15 prompts.

## Before the first run
- Freeze prompt version and locale (default `en-IN`) for the baseline window.
- Record platform/product version only when exposed; otherwise `unknown`.
- Capture exact prompt, timestamp, method, complete answer, citations and evidence reference.
- Run ChatGPT, Gemini and Perplexity separately. Add Copilot and Google AI surfaces only when directly accessible and clearly identified.
- Never treat general web-search results as an AI-chat response.
- Never count ERROR, BLOCKED or NOT_RUN as ABSENT.

## Cycle allocation
| Week | Prompt IDs | Work |
|---|---|---|
| 1 | RE-001–RE-015 | Pilot baseline; validate capture procedure and schema |
| 2 | RE-016–RE-030 | Run and quality-check evidence |
| 3 | RE-031–RE-045 | Run, compare platform coverage and failure rates |
| 4 | RE-046–RE-060 | Complete cycle; consolidate monthly baseline |

## Observation workflow
1. Select one prompt and lock exact text.
2. Run independently on each accessible platform.
3. Save raw answer evidence before classification.
4. Classify mention, recommendation and citation independently.
5. Record competitors and exact cited URLs.
6. Second-pass review ambiguous classifications.
7. Produce coverage and outcome rates with numerator, denominator, platform and time window.
8. Create recommendations only after baseline is complete; technical or public changes remain approval-gated.

## Monthly metrics
- Prompt coverage = successful observations / planned observations.
- Platform coverage = prompts successfully run / prompts scheduled for that platform.
- Mention rate, recommendation rate and citation rate are separate.
- Competitor appearance rate is reported separately.
- Error and blocked rates remain visible.
- Report exact observation window and sample size; do not imply ranking, traffic, leads or revenue.

## Current execution state
No genuine AI-platform answers have been captured in the available evidence set as of 2026-11-01. This is a runbook, not a claim that the four cycles have run.
